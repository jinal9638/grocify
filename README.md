###  Features Highlighted in Demo:
-  **Dynamic Shopping Cart**: Real-time quantity adjustments and subtotal recalculation.
-  **Wishlist Drawer**: Save favorite organic items with badge counter updates.
-  **Live Search Bar**: Instantly filters products in real time as you type item names.
-  **Category Filtering**: Seamlessly filter organic produce by categories (*Fruits*, *Veggies*, *Dairy*, *Juices*, *Bakery*, or *All*).
-  **SPA Page Navigation**: Smooth view switching between the Storefront and the **About Us** page without page reloads.
-  **Dark Mode Toggle**: Smooth theme switching using Tailwind classes.
-  **Responsive Design**: Full mobile menu support across all screen sizes.
